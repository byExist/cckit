# lab

하네스 구성 요소를 실험하고 계측하는 도구 모음입니다.

## bench

`/bench [대상 요소] [축]`으로 호출합니다. 스킬 지침·훅·에이전트 등록·CLAUDE.md 지침 등 하네스 구성 요소의 변형을 격리 실행하고, 셀별 크기 변화·토큰·시간·비용을 표로 보고합니다. 품질 판정은 하지 않습니다. 판정 기준은 대상의 tests/에 있으며, 해석은 호출자의 몫입니다.

요소마다 주입 경로와 관찰 채널이 달라서, 요소별 검증 방법은 [references/](skills/bench/references/)의 안내서에 정리되어 있습니다 (검증된 방법과 미해결 지점을 구분해 적었습니다).

- 기본 매트릭스는 셀 9개 이하로 작게 잡고, 실행 전에 셀 수와 예상 토큰을 확인받습니다.
- 비용은 실행 시점의 모델 단가를 조회해 근사치로 병기합니다.
