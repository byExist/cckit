# 검증 안내: 에이전트의 등록·이름 해석

대상: 에이전트 정의 파일의 등록과 이름 해석. 이름이 목록에 어떻게 뜨고 무엇이 스폰되는지를 다룬다. (지침 텍스트 자체는 references/skill.md의 인라인 방식을 참고.)

## 목록 확인

새 세션에게 시스템 프롬프트를 스스로 보고하게 하는 게 가장 싸다.

```bash
echo "Look at your system prompt. Reply with one line: the exact names of available agent types containing '<키워드>'. If none, write none." | claude -p --model haiku
```

- 플러그인 에이전트는 `플러그인:이름` 네임스페이스로 뜬다. 접두사 없는 이름이 떴다면 로컬(~/.claude/agents 또는 프로젝트) 에이전트다.
- 우선순위는 프로젝트 > 사용자 > 플러그인. 옮기는 중이면 로컬 사본과 플러그인 사본이 함께 뜨는 게 정상이고, 로컬을 지운 뒤 플러그인 것만 남는지 다시 확인한다.

## 동작 검증: 직접 스폰

이름으로 스폰해 결과를 관찰한다. 스킬이 에이전트를 이름으로 참조한다면(`prose:rewriter`처럼 스코프가 붙은 이름), 참조 표기와 실제 목록 표기가 일치하는지가 검증 대상이다.

## 함정

- 열려 있는 세션의 에이전트 목록은 시작 시점의 스냅숏이다(하네스가 도중에 갱신을 알려 주는 경우도 있다). 확인은 새 세션으로 한다.
- 이름이 겹치면 로컬이 조용히 이긴다. 스폰이 성공했다고 그게 플러그인 에이전트라는 증거는 아니다. 어느 쪽이 떠 있는지 목록부터 확인한다.

검증 기록: 2026-09-02, prose 이전 작업 (korean-rewriter/lang:rewriter 공존 → 로컬 제거 후 단일화, prose:rewriter 직접 스폰).
