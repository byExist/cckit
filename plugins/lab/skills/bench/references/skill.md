# 검증 안내: 스킬·에이전트의 지침 텍스트

대상: SKILL.md 본문, 에이전트 정의의 지침부. 모델이 따르는 지침 텍스트다.

## 검증 방식: 인라인 (서브에이전트에 직접 주입)

지침은 텍스트라서 로딩 경로 없이 검증할 수 있다. 셀마다 격리된 서브에이전트를 하나 띄우고, 프롬프트를 다음 형태로 만든다.

```text
다음 지침을 그대로 수행하라.

---
<지침 변형 전문>
---

대상: <사본 경로> (이 파일만 읽고 수정하라)
<독자·목적 등 스킬의 인자>
```

- 모델 축은 Agent 호출의 model 파라미터로 정한다.
- 셀들은 병렬로 띄운다. 사본이 셀마다 나뉘어 있으면 서로 간섭하지 않는다.
- 위임형 스킬(디스패처 + 에이전트)은 에이전트 쪽 지침을 이 방식에 넣으면 된다. 디스패처의 위임·검토 흐름까지 보려면 실행 형태 축을 "단일 실행 / 위임+검토" 2단으로 나눈다.

## 이 방식이 검증하지 못하는 것

frontmatter 해석, 스킬 이름 해석, 짧은 이름 호출, 플러그인 로딩은 지침이 아니라 등록·로딩의 문제다. 이런 것은 실제 세션으로 확인한다: 새 세션에서 `claude -p "/스킬명"`을 호출해 unknown command 에러가 없는지, 응답이 스킬 본연의 흐름인지 본다. `disable-model-invocation: true` 스킬은 모델용 Skill 목록에 안 뜨는 게 정상이므로, 목록에 없다고 오판하지 말 것.

## 함정

- 실행자가 대상 파일 밖(특히 tests/)을 읽을 길을 열지 말 것. 지침을 파일 경로가 아니라 인라인으로 주는 이유다.
- `claude -p`는 프롬프트를 stdin으로 넘긴다. `--debug`가 다음 인자를 필터로 삼켜 프롬프트가 사라지는 사고가 있다.
