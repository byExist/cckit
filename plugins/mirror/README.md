# mirror

하네스가 고정 파일명으로 읽어들이는 지침 파일(`CLAUDE.md`, `CLAUDE.local.md`, `SKILL.md`)과 사용자 언어 번역본을 같은 내용으로 유지하도록 에이전트에게 알려주는 Claude Code 플러그인입니다. 파일을 직접 고치지는 않고 컨텍스트만 주입합니다.

## 동작 방식

PostToolUse(`Edit|Write|MultiEdit`) 훅이 지침 파일 편집을 감지합니다.

- 원본(예: `SKILL.md`)이 편집되고 같은 디렉터리에 번역본(예: `SKILL.ko.md`)이 있으면, 번역본을 함께 갱신하라는 안내를 주입합니다.
- 번역본이 편집되면 원본과 내용을 맞추라는 안내를 주입합니다.
- 그 외에는 침묵합니다: 지침 파일이 아닌 편집, 번역본이 없는 디렉터리의 원본 편집, 언어 설정이 없거나 영어인 경우.

## 번역본 규칙

- 파일명은 `<원본 이름>.<언어 코드>.md`입니다. 예: `CLAUDE.md` → `CLAUDE.ko.md`.
- 언어 코드는 `~/.claude/settings.json`의 `language` 값에서 뽑습니다. 언어 이름(`한국어`, `japanese` 등)과 ISO 코드(`ko`, `zh-tw` 등)를 모두 받습니다.
- 디렉터리별 opt-in입니다. 번역본 파일을 만들어 두면 그 디렉터리에서만 동기화 알림이 켜집니다. 애초에 사용자 언어로 쓰인 지침에는 알림이 나가지 않습니다.

## 대상 파일

고정 파일명으로 발견되는 지침 파일만 다룹니다. `.claude/rules|agents|commands|output-styles/` 아래처럼 디렉터리 안의 임의 파일명이 모두 로드되는 곳은 제외합니다. 번역본을 옆에 두면 그 파일 자체가 규칙·에이전트·커맨드로 로드되어 버리기 때문입니다. `MEMORY.md`도 제외합니다. 사용자가 작성·검수하는 지침이 아니라 에이전트의 자동 메모리입니다.
