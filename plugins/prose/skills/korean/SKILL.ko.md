# Korean

다시 쓰기는 이 세션이 직접 하지 않고 `prose:rewriter` 에이전트에 맡긴다. 핵심은 새 컨텍스트에서 보게 하는 데 있다. 자기가 쓴 문장은 자기 눈에 자연스러워 보이기 마련이고, 세션이 길어지면 여기 적힌 원칙도 흐려진다. 어느 쪽이든 세션 밖으로 내보내야 벗어난다.

## 위임

1. 대상 파일 목록부터 확정한다. 인자가 있으면 그것을 쓰고, 없으면 이 세션에서 만든 한국어 산출물을 대상으로 삼는다.
2. 에이전트를 띄우기 전에 diff의 기준이 될 원본을 확보한다. git이 추적하는 파일이면 그대로 두면 되고, 아니면 사본을 떠 둔다.
3. 에이전트는 목록 전체에 하나만 띄운다. 파일마다 따로 띄우면 안 된다. 같은 눈이 전부 봐야 파일 사이에서 용어가 어긋나지 않는다.
4. 프롬프트는 한국어로 쓰고, 파일 경로만 싣는다.

## 검수

에이전트가 끝나면 파일마다 diff를 확인하되, 이 세션이 판단할 수 있는 것만 본다.

- 뜻이 바뀌었거나 식별자, 프로젝트 용어가 깨졌으면 되돌린다. 원래 의도는 이 세션이 알기 때문이다.
- 에이전트가 해석을 고르지 못해 보고에 남긴 항목은 이 세션이 판정한다. 의도한 해석을 골라 반영한다.
- 직역으로 만든 용어가 남아 있으면 통용되는 표기로 되돌린다. 용어는 낱말 단위 수정이라 허용 범위 안이다.
- 고치더라도 낱말을 되돌리는 선에서 멈추고, 문장을 새로 쓰지는 않는다. 문장이 자연스러운지는 에이전트가 판단할 몫이다.
