# 회귀 시료

prose:rewriter 정의를 고친 뒤 행동이 달라지지 않았는지 확인하는 고정 시료. exp-a.md와 exp-b.md는 영어 컨텍스트 위에서 sonnet이 생성한 한국어로, 전형적인 번역투 파손을 담고 있다 (2026-09-01 채집). exp-c.md는 영어 원본과 나란히 작성된 한국어 미러(cckit bench SKILL.ko.md)로, 문장 단위 직역은 드물지만 구조 수준 번역투 — 무생물 주어의 소유·행위문, 대시 리듬 — 를 담고 있다. 구조 항목이 없던 구버전 교리가 거의 그대로 통과시킨 표본이다 (2026-09-02 채집).

## 절차

1. 시료를 임시 디렉터리로 복사한다. 이 디렉터리의 원본은 그대로 둔다.
2. 정의를 수정한 직후라면 반영 지연(실측 약 2분)을 기다린 뒤, 진단 스폰("네 지침에 X가 있는지 예/아니오로 답하라. 파일은 고치지 말라")으로 새 지침 수신부터 확인한다.
3. prose:rewriter를 복사본 경로만 실어 하나 띄운다.
4. 복사본을 원본과 diff로 대조해 아래 기준으로 판정한다.

## 판정 기준

반드시 잡아야 하는 것 (기준선 6/6):

- exp-a 마지막 문장 "~하는 것을 막는 데 효과적인 방법이다" — 영어 골격(an effective way to)에 주어 실종. 동작과 결과를 잇는 문장으로 재작성되어야 한다.
- exp-b 첫 문장 "동시성 제어를 ~ 가정이 반대다" — 조사가 어긋난 비문. 문법이 성립하는 문장으로 재작성되어야 한다.

- exp-c "판정 기준과 시료는 대상의 tests/가 소유하고" — 무생물 소유 구조. 한국어 문장으로 재작성되어야 한다.
- exp-c "이 스킬은 결과를 나란히 놓는다" — 무생물 행위 구조. 한국어 문장으로 재작성되어야 한다.

지켜야 하는 것 (위반하면 회귀):

- exp-b 첫 문장의 '시점' 해석. '빈도'로 바꾸면 뜻 변경이다.
- 명사형 종결 목록, "예외를 던지고" 같은 정착 관용구, `model`·`SELECT FOR UPDATE` 같은 식별자.
- exp-c의 frontmatter, 목록 구조, "텍스트 릭"·"실기 릭" 같은 프로젝트 용어와 `claude -p`·`tests/` 같은 식별자.
- 완료 보고에 판단 보류 여부가 명시되어야 한다 (책임 조항 이행).

계약 밖 (잡으면 보너스, 안 잡아도 회귀 아님):

- "컨텍스트 창" → "컨텍스트 윈도우" 같은 단어 층위 조어 (기준선 1/6). 단어 층위는 지침이 아니라 스킬 검수 단계의 용어 패스가 담당한다.
