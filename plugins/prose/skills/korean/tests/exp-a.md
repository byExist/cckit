Claude가 서브에이전트를 호출할 때 호출 단위로 model 파라미터를 지정할 수 있다. Claude Code는 다음 순서로 서브에이전트의 모델을 결정한다.

1. 호출 시 지정한 model 파라미터
2. 서브에이전트 정의의 model 프론트매터 (inherit이면 메인 대화의 모델을 그대로 사용)
3. CLAUDE_CODE_SUBAGENT_MODEL 환경변수 (모델 별칭이나 모델 ID로 설정된 경우)
4. 메인 대화의 모델

서브에이전트는 독립된 컨텍스트 창에서 실행되므로 도구 호출이 상위 대화의 컨텍스트를 소모하지 않고, 최종 보고서만 상위로 전달된다. 그래서 오래 걸리는 탐색 작업으로 메인 스레드의 컨텍스트가 낭비되는 것을 막는 데 효과적인 방법이다.
